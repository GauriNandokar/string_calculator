# StringCalculator (Ruby)

A simple String Calculator in Ruby using TDD.  
Supports addition from strings, custom delimiters, negative number validation, numbers >1000, and event callbacks.

## Installation
1) git clone https://github.com/GauriNandokar/string_calculator.git
2) cd string_calculator
3) bundle install

## Running Test Cases
bundle exec rspec spec/string_calculator_spec.rb
